# NODO QUICK START

1. Setup
   nodo config

2. Get a service
   nodo download <url>
   OR
   nodo import <path>

3. Build your own
   nodo pack <folder>

4. Share it
   nodo publish <service>

5. Run it
   nodo execute <service>

EXTRAS

Remote run:
   nodo execute --remote <service>

Export package:
   nodo export <service> <dir>

Raw .celaut:
   nodo export <service> <dir> --raw
