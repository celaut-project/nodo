# Proposals

Design documents and studies written for a specific issue. Each one keeps an **audit**
of the code as it stands, with every claim citing a file or function, separate from the
**design** or argument built on it. The user-facing behaviour they lead to is documented
in the main `docs/` pages, which link back here.
